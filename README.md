# Linuxと目覚めるアラームちゃん

LPIC の問題に正解しないと止まらない、スマホ向けの目覚ましアラーム（PWA）。
LPIC-2（201 / 202 試験）の頻出問題を中心に **320 問** 収録。アラームなしで解く学習モードもある。

## 主な機能

| 画面 | できること |
| --- | --- |
| アラーム | 時刻・曜日・停止に必要な正解数（1〜10 問）・出題範囲を設定。おやすみモード、鳴動テスト |
| 学習 | 201 / 202 をワンタップで 10 問、苦手の復習、未出題に挑戦、主題（200〜212）を絞って出題 |
| 記録 | 解答数・正答率・起床回数・苦手な問題数、カテゴリ別と LPIC-2 主題別の正答率 |
| 設定 | 頻出問題の優先、音をだんだん大きく、バイブ、画面スリープ防止、音の確認、通知の許可 |

- 鳴動中は停止ボタンがなく、設定した数だけ正解すると止まる。リロードしても戻るボタンを押しても止まらない。
- 試験の頻出度（`freq`）と自分の正誤記録から出題を重み付けする。最頻出の問題と直近で間違えた問題ほど出やすく、安定して正解できている問題は出にくい。
- 解答後に正答と解説を表示する。
- 選択肢の並びは毎回シャッフルされる。
- コマンド入力では、スマホで起きやすい入力の揺れを吸収する（全角英数字、先頭の自動大文字化、iOS で `--` が `—` に変わる、`sudo` や `$` の付け忘れ・付けすぎ、引用符の違いなど）。
- 外部ライブラリなし。オフラインでも動く。

## 収録問題

LPIC-2 は現行の **バージョン 4.5（201-450 / 202-450）** の出題範囲に沿っている。最新の出題範囲は [LPI 公式サイト](https://www.lpi.org/) で確認すること。

| 試験 | 主題 | 問題数 |
| --- | --- | ---: |
| 201 | 200 キャパシティプランニング | 11 |
| 201 | 201 Linux カーネル | 29 |
| 201 | 202 システムの起動 | 21 |
| 201 | 203 ファイルシステムとデバイス | 22 |
| 201 | 204 高度なストレージ管理 | 23 |
| 201 | 205 ネットワーク構成 | 14 |
| 201 | 206 システムの保守 | 18 |
| 202 | 207 DNS | 32 |
| 202 | 208 HTTP サービス | 28 |
| 202 | 209 ファイル共有 | 23 |
| 202 | 210 ネットワーククライアント管理 | 23 |
| 202 | 211 電子メールサービス | 21 |
| 202 | 212 システムセキュリティ | 31 |
| — | 現場頻出 / LPIC-1 / マニアック | 各 8 |

形式は単一選択・複数選択（「◯つ選択」）・コマンド入力・記述式（ファイル名や設定項目を入力）の 4 種類で、本番と同じく選択式と記述式の両方がある。

## スマホで使う

### 1. HTTPS で公開する（GitHub Pages）

ホーム画面に追加したり、通知・画面スリープ防止を使ったりするには HTTPS で配信する必要がある。

1. GitHub のリポジトリで **Settings → Pages** を開く。
2. **Build and deployment** の Source を「Deploy from a branch」にし、ブランチ `main`・フォルダ `/ (root)` を選んで保存する。
3. 数分後に `https://<ユーザー名>.github.io/-Linux/` で開けるようになる。

非公開リポジトリで GitHub Pages を使えるかどうかは、GitHub の契約プランによる。

### 2. ホーム画面に追加する

- **iPhone（Safari）**: 共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**: メニュー → 「アプリをインストール」（設定画面にボタンが出ることもある）

### 3. 確実に鳴らすには

Web アプリは、画面ロック中やバックグラウンドにいる間、OS の省電力機能でタイマーや音が止められることが多い。そのため次の使い方を推奨する。

- 寝る前に **おやすみモード** にして、画面を点けたまま充電しておく（画面スリープを防ぎ、時計を暗く表示する）。
- **鳴動テスト** で音量を確認する。iPhone はマナーモード中だと鳴らないことがあるので、実際の設定で一度試しておく。
- 設定で **通知を許可** しておくと、バックグラウンドでも鳴った瞬間に通知が出る（端末によっては出ない）。
- アプリが止まっていて時刻に鳴らせなかった場合、30 分以内に開けばその時点で鳴る。それより遅いとアラーム画面に「鳴りませんでした」と表示される。

### PC で動作確認する

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:4173/index.html` を開く。

## 問題の追加

問題データは `questions/` にある。

| ファイル | 内容 |
| --- | --- |
| `questions/core.js` | 現場頻出 / LPIC-1 / マニアック |
| `questions/lpic201.js` | LPIC-2 201 試験（主題 200〜206） |
| `questions/lpic202.js` | LPIC-2 202 試験（主題 207〜212） |

各ファイルの配列に、次の形式で追加する。

```js
{
  id: "207-allow-transfer",  // 一意な ID。LPIC-2 は主題番号で始める
  category: "lpic202",       // field / lpic1 / lpic201 / lpic202 / deep
  topic: "207",              // LPIC-2 の主題番号（LPIC-2 は必須）
  freq: 3,                   // 出題頻度 3: 最頻出 / 2: 頻出 / 1: 押さえておきたい（LPIC-2 は必須）
  type: "single",            // single / multi / command / fill
  text: "問題文",
  options: ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
  answer: [0],               // 正解の選択肢の番号（0 始まり）
  hint: "ヒント",
  explain: "解答後に表示する解説",  // LPIC-2 は必須
}
```

- **複数選択**: `type: "multi"` にして `answer: [0, 2]` のように複数指定する。問題文に「2 つ選択せよ」と書くと、数の食い違いを検証スクリプトが検出する。
- **コマンド入力 / 記述式**: `type: "command"` または `"fill"` にし、`options` / `answer` の代わりに `answers: ["正答1", "別解2"]` と `match` を指定する。
  - `match: "normalized"`: 空白・引用符・全角文字などを正規化したうえで完全一致。
  - `match: "orderedTokens"`: 正答の単語が同じ順番ですべて含まれていれば正解（オプションの追加を許容）。
  - `ignoreCase: true`: 大文字小文字を区別しない（Apache のディレクティブ名など）。
- **`noShuffle: true`**: 選択肢をシャッフルしない（数値を小さい順に並べた問題など）。
- 問題文で空行（`\n\n`）より後ろはコードブロックとして等幅で表示される。ゾーンファイルや設定ファイルを見せるときに使う。

追加・編集したら検証スクリプトを実行する。

```bash
node tools/check-questions.js
```

ID の重複、正解番号の範囲外、「◯つ選択」と正解数の食い違い、記述式の正答が判定ロジックで正解にならない、などを検出する。

問題を更新したら `sw.js` の `CACHE_NAME` の番号も上げる。上げないと、インストール済みのアプリに古い問題が残る。

## ファイル構成

```
index.html            画面
styles.css            スタイル（スマホ前提・ダークテーマ）
app.js                アラーム・出題・記録のロジック
matcher.js            コマンド入力の正誤判定
questions/            問題データ
sw.js                 Service Worker（オフライン対応・通知）
manifest.webmanifest  PWA の設定
tools/                問題データの検証スクリプト
assets/               アイコン
```

設定・学習記録は端末のブラウザ（localStorage）にだけ保存される。別の端末とは同期されない。
